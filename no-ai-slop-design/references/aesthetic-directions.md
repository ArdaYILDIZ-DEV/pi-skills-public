# Problem-led repairs

Read when a supported finding needs a concrete repair. Keep the existing identity unless replacement is authorized. Full art-direction selection belongs to the constructive skill; this file does not duplicate its style catalog.

| Diagnosed cause | Repair | Preserve / recheck |
|---|---|---|
| Primary task buried | Raise its position/contrast; demote supporting content | Existing action, destination, keyboard order |
| Text roles flat | Tune role sizes/weights, measure, and leading | Fitting font; real titles/locales/zoom |
| Card soup | Group by task, remove redundant containers, feature real proof | Equal treatment for comparable entities; shared component contracts |
| Color competes or fails contrast | Adjust the failing semantic consumer/state, not the whole brand | Approved seeds, status meaning, actual pair measurements |
| Data loses scanability | Align columns/numerals; expose exceptions near controls | Table keys, sorting, bindings; narrow-slot overflow |
| Decoration replaces substance | Remove empty badges/effects; show authorized output or concrete explanation | Meaningful identity motif, credits, metadata; truthful claims |
| Responsive/state gaps | Repair intrinsic sizing, navigation, focus, error/loading paths | Critical actions/data; keyboard and reduced-motion behavior |

State **retain → change → reason → recheck** before a substantial rewrite. Link related repairs; avoid collecting unrelated “tasteful” attributes. Escalate a system-level defect as advice rather than replacing approved tokens in a component pass.

**Operational example:** keep the single sans, green brand, and table; promote payout exceptions, flatten extra panels, align currency. No hero, new font, or photo is needed.

**Editorial example:** keep warm paper, serif, and issue metadata; fix prose measure and verify Turkish glyphs/casing and long-title wraps. Do not apply a technical theme to avoid familiar editorial choices.

**Failure:** swap the entire palette/font and add asymmetry while preserving the same weak content hierarchy. A different preset is not a cause-level repair.
