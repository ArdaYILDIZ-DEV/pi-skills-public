# C: Doxygen / kernel-doc, MISRA-safe

Read `SKILL.md` first; this file only carries what is C-specific.

## Baseline standard

C has no built-in documentation mechanism, so the house tool decides the format:

- **Doxygen** (`/** ... */` with `@param`, `@return`, `@note`): the de-facto default for
  libraries, firmware and applications.
- **kernel-doc** (`/** ... */` with `@arg:`, `Return:`, `Context:`): Linux-kernel-style trees.
- **Plain `/* ... */`** when the project runs no doc generator. Never write `/**` unless the
  project extracts it; an unmaintained Doxygen block is worse than none.
- **`//` is standard since C99** but *match the file*. Kernel-style, MISRA-derived and most
  embedded houses use `/* */` exclusively.
- **MISRA C:2023 Rule 3.1 (Required):** `/*` and `//` shall not appear *inside* a comment.
  GCC/Clang `-Wcomment` catches this. Never nest comments; beware URLs (`https://...`)
  inside a `/* */` block on a MISRA project.
- **The header is the contract.** Public API in `.h`, implementation in `.c`. Contracts go
  in the header; rationale in the source. Duplicate neither.
- Arbiters: `clang-format`, `clang-tidy`, `cppcheck`, `doxygen`, `-Wdocumentation`,
  MISRA/CERT checkers.

## Pre-flight (never skip)

1. **Detect the house style:** `/* */` only or `//` allowed? Doxygen, kernel-doc, or plain?
   Comment language? Banner template, if any?
2. **Read the config:** `.clang-format`, `.clang-tidy`, `Doxyfile`, `compile_commands.json`,
   MISRA/CERT deviation records. Configured tooling overrides every rule below.
3. **Read before judging**, including call sites and the datasheet/API doc a register or
   magic constant refers to.
4. **Never document** generated or vendored code: `*pb-c.c`, autogenerated headers, `build/`.

## Priority-1 signals (lies)

| Defect | Signal |
|---|---|
| Contradicts the code | says "returns 0 on error" but returns `-1` |
| Signature drift | `@param` names a removed/renamed argument; a new parameter is undocumented |
| Phantom contract | `Return:` documents a value never produced; `@note` promises a lock that isn't taken |
| Stale reference | old errata number, datasheet revision, or ticket |

## Priority-3 shapes (move / compress)

| Defect | Action |
|---|---|
| Contract (ownership, error codes, blocking, locks) as an inline comment in the `.c` | **MOVE** to the header's doc block |
| Implementation rationale inside the header block | **MOVE** to the `.c`, next to the code |
| Contract duplicated in `.h` and `.c` | **KEEP** `.h` authoritative; delete or reduce the copy |
| Banner around a 5-line static helper | **COMPRESS** to one line, or delete |

Anti-churn, C-specific: **`#if 0 ... #endif` is code, not a comment.** Flag it; never delete
it as "commented-out code" and never edit inside it.

## Triggers: write a comment here

| Trigger | Example that passes the wrong-edit test |
|---|---|
| Memory ownership & lifetime | `/* Caller owns buf and must free() it; NULL on allocation failure. */` |
| Buffer contract | `/* dst must hold len + 1 bytes; this routine writes the NUL. */` |
| Units | `/* Period is in bus ticks (1 tick = 12.5 ns), not nanoseconds. */` |
| Hardware semantics | `/* Read-to-clear: reading STATUS also acknowledges the interrupt. */` |
| Endianness / layout | `/* Wire format is big-endian regardless of host; struct is __packed. */` |
| Concurrency / context | `/* Called from ISR context: no blocking, no locks held. */` |
| Lock order | `/* Acquire dev->lock before bus->lock; the reverse deadlocks with .probe(). */` |
| Error convention | `/* Returns negative errno; -EAGAIN means retry after the poll interval. */` |
| Errata / workaround | `/* Two dummy reads required after reset (silicon errata ES-0441 §3). */` |
| Deliberate inefficiency | `/* Byte copy, not memcpy: the region is not DMA-coherent. */` |
| Magic constant's origin | `/* 0x5A = unlock key from the datasheet, §12.4. */` |
| Overflow assumption | `/* Cannot overflow: len is bounded by MAX_FRAME (255) at the call site. */` |
| Aliasing / `restrict` | `/* src and dst must not overlap; no alias check is performed. */` |
| Intentional fallthrough | `/* fallthrough */` (required by `-Wimplicit-fallthrough`) |
| Non-obvious macro | `/* Expands x twice - never pass an expression with side effects. */` |

## Never write these (C forms)

```c
/* NO: restatement */
/* increment i */                    ->  i++;
/* check if the device is ready */   ->  if (dev->ready)

/* NO: Type in prose */
/* the count */ int count;

/* NO: Nested-comment traps (MISRA 3.1, -Wcomment) */
/* See https://vendor.example.com */   /* a URL smuggles "//" into the block */

/* NO: Empty Doxygen scaffolding */
/** @brief Sets the value.
 *  @param v the value
 *  @return the value
 */
```

Upgrade table:

| You find | Do this |
|---|---|
| `/* sort the array */` | **Delete**, unless order matters: `/* Stable order required: caller matches by index. */` |
| `/* magic number */` | **Rewrite** with the source: `/* 0x5A = unlock key, datasheet §12.4. */` |
| `/* don't touch this */` | **Rewrite** as why: `/* Register is write-once; a second write is ignored, not queued. */` |
| Author/date banner | **Delete the scaffolding**, keep any surviving contract in a doc block. |

## Comment craft (C specifics)

- `/* ... */` for blocks; `//` for short trailing comments where the file allows it. Pick
  one per file.
- **Never nest.** To disable code temporarily use `#if 0 ... #endif`, or delete it.
- Width: match the project (80 is the common default).
- **`/**` is a promise.** Only open a doc block where the generator will pick it up.

## API documentation

| Location | Contents |
|---|---|
| **`.h` (contract)** | Purpose, parameters, ownership/lifetime, error codes, blocking, thread/ISR safety, valid ranges, units. |
| **`.c` (rationale)** | Why this algorithm, hardware quirks, errata, perf trade-offs, lock ordering. |

```c
/**
 * sensor_read() - Reads one sample from the sensor into @buf.
 * @dev: Sensor to read; must be powered and out of reset.
 * @buf: Destination buffer, at least @len bytes. Untouched on error.
 * @len: Bytes to read; must be a multiple of 4 or the FIFO stalls.
 *
 * Blocks until a sample is ready. Do not call from interrupt context.
 *
 * Return: Number of bytes read on success, negative errno on failure:
 * -EAGAIN if no sample is ready yet, -EIO if the CRC check fails.
 */
int sensor_read(struct sensor *dev, uint8_t *buf, size_t len);
```

- Kernel trees: kernel-doc spelling (`@arg:`, `Return:`, `Context:`).
- Document the **caller's obligations**, not the implementation's steps.
- `Return:` names real values, including which errno means what.

| Declaration | Default |
|---|---|
| Public function (in `.h`) | Full doc block. |
| `static` / internal function | One line only when non-obvious. |
| `struct` / `union` | Purpose; members only when non-obvious (units, range, reserved). |
| Packed / hardware-mapped struct | **Always** document endianness, alignment, reserved bits. |
| `enum` | Meaning; call out wire/ABI-fixed values. |
| Typedef | What it represents, not "typedef for X". |
| Function-like macro | **Always** document multiple evaluation and unusual parenthesisation. |
| Object-like macro | Unit and meaning: `#define TIMEOUT_MS 250  /* worst-case per datasheet §7 */` |
| Global variable | Ownership, who writes it, the lock protecting it. |
| Include guard / `#pragma once` | Nothing. |

## Calibration example

```c
/* BEFORE (4 defects, 6 gaps) */
/*************************************************************
 * Function: read_frame
 * Author: jsmith          Date: 2019-04-01
 * Description: reads a frame
 *************************************************************/
int read_frame(struct device *dev, uint8_t *buf, size_t len)
{
        /* loop through the buffer */
        for (int i = 0; i < len; i++)
                buf[i] = ioread8(dev->base + FRAME_REG);

        /* returns 0 on error */
        if (crc16(buf, len) != ioread16(dev->base + CRC_REG))
                return -1;

        /* old: memcpy(buf, dev->shadow, len); */
        return len;
}
```

```c
/* AFTER */
/**
 * read_frame() - Reads one frame from the device FIFO into @buf.
 * @dev: Device to read; must be powered and out of reset.
 * @buf: Destination buffer, at least @len bytes. Untouched on error.
 * @len: Bytes to read; must be a multiple of FRAME_ALIGN or the FIFO stalls.
 *
 * Blocks until the frame completes; do not call from interrupt context.
 *
 * Return: @len on success, or -1 if the frame CRC does not match the value
 * the device computed for it.
 */
int read_frame(struct device *dev, uint8_t *buf, size_t len)
{
        /* Byte-wise on purpose: the FIFO is not DMA-coherent and 4-byte
         * bursts reset the read pointer (errata ES-0441 §3). */
        for (int i = 0; i < len; i++)
                buf[i] = ioread8(dev->base + FRAME_REG);

        if (crc16(buf, len) != ioread16(dev->base + CRC_REG))
                return -1;

        return len;
}
```

**Deleted:** banner, restatement, false `returns 0` claim, commented-out `memcpy`.
**Added:** FIFO rationale, context warning, buffer/alignment contract, real return
convention. **Flagged:** `-1` instead of negative errno, inconsistent with the driver.

## Language self-check

- [ ] `/* */` vs `//`, Doxygen vs kernel-doc vs plain, lint config detected?
- [ ] `@param` names match the prototype; `Return:` values are real?
- [ ] No `/*` or `//` inside any comment; `#if 0` blocks flagged, not deleted?
- [ ] Contract in `.h`, rationale in `.c`, nothing duplicated?
- [ ] Macros documented for side effects; hardware structs for layout?
