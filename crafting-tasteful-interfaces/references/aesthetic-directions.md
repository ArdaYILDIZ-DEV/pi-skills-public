# Art direction

Read for custom direction selection, not routine component extensions. Choose from actual task/content and audience posture; style labels are vocabulary, not industry assignments.

Before markup, link **subject anchor → hierarchy/composition → type/color/shape → characteristic detail → validation risk**. Explain why the choices belong together. Ask only if competing directions materially change an unapproved outcome. A physical metaphor, new font, or decorative signature is not required.

| Stance | Useful organizing choices | Common failure |
|---|---|---|
| Swiss / typographic | Neutral type roles, aligned data, whitespace/rules, scarce signal accent | Anonymous emptiness |
| Industrial / operational | Exception-first work area, readable dense rows, actual code/readouts | Fake terminal styling or tiny text |
| Editorial / literary | Reading measure, title/body/metadata roles, real stories/annotations | Serif accent word + clay as the entire identity |
| Luxury / refined | Product detail, deliberate space, quiet competing emphasis | Hidden actions or low-contrast small text |
| Humanist / organic | Welcoming type, soft grouping, fitting media, clear states | Automatic cream/sage palette |
| Playful / kinetic | Readable task spine, composed multi-color roles, tactile feedback | Animation everywhere or hue-only meaning |
| Neo-brutalist / raw | Robust type, flat color, deliberate rules/hard shadows | Unrequested black-border makeover |
| Geometric / art deco | Coherent motif, framing and intentional symmetry | Ornament around every control |
| Retro-futuristic / Y2K | Explicit era reference, media/display/chrome treated together | Scanlines/glows obscuring content |
| Maximalist / layered | Strong anchor and reading order within expressive layers | Randomness mistaken for originality |
| Warm minimal / restrained | Exact role hierarchy, spacing and state craft | Another “safe tasteful” preset |

## Contrasting examples — hypothetical

**On-call incident workspace:** medium variance, high density, low motion. Existing sans with tabular durations; exception queue dominates beside an evidence panel; status labels accompany colors. Identity comes from queue-to-evidence alignment. Test narrow desktop slots, keyboard selection, long names, and sticky-header focus.

**Turkish culture journal:** reading-led serif or text sans, fitting paper/ink, useful issue metadata, featured essay and quieter secondary stories; little/no motion. Test actual Turkish glyphs/casing, long titles, 60–70ch starting measure, covers, and zoom. Do not copy operational dashboard density.

**Youth workshop booking:** preserve requested violet/coral; expressive display with readable UI, equal cards for comparable sessions, a shared shape motif and modest reactive motion. Booking stays conventional. Verify on-action/focus contrast, non-color selection, mobile fields, static/reduced-motion usability, and factual availability.

Borrow mechanisms from case studies—not brand appearances: Linear's text/data roles, Resend's command/output proof, Stripe's state tokens, Vercel's spacing discipline. A paid font, exact dark canvas, or glow is not a universal quality marker.

Reject a direction that fits any unrelated brief unchanged. Reconsider habitual palettes/compositions, but do not require novelty across projects or abandon an appropriate existing identity.
