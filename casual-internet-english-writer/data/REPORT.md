# Casual internet English research report

The inherited Reddit-focused package remains the main substantive evidence base for the casual skill. Its strongest usable contribution is qualitative: direct participation, active agency, concrete detail, local hedging, flexible rhythm, and artifact-specific differences between posts and replies.

The old composition pipeline underused those observations by applying one grammar-forward cleanup pass to professional and casual artifacts. The split should let the casual skill preserve harmless fragments, simple conjunctions, asides, and uneven cadence while still rejecting forced slang and fabricated errors.

Historical templates and anti-pattern families are retained as optional editorial diagnostics. Fixed word counts, connector rates, mandatory endings, numerical rhythm formulas, and universal absence claims remain non-operational because the raw ledger and item-level verification are unavailable.

Current Reddit verification was attempted but blocked anonymously. Candidate pages and search snippets are not cited as fetched evidence. The user approved implementation using the inherited corpus with this limitation recorded.
